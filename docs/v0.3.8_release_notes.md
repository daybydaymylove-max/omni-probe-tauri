# Omni-Probe v0.3.8 Release Notes

Omni-Probe v0.3.8 represents a major production release featuring **a complete professional network capture subsystem, sub-millisecond BPF offline validation engine, and a hardcore four-fold storage and retrieval architecture** (Streaming Raw Frame PCAP Persistence, Multi-GB PCAP Two-Level Sparse Indexing, High-Precision Nanosecond Replay, and Universal Multi-Bus Diff/Analysis).

---

## 🌟 Key Highlights

### 1. Professional Packet Capture Modal & Sub-millisecond BPF Engine (`NetworkCaptureModal.vue` / `sniffer.rs`)
- **NIC Hardware Profiling**: Deep OS-level traversal of network adapters, clearly identifying physical interface type (Ethernet vs. Wi-Fi), IP bindings, and automatically recommending the default internet egress gateway.
- **Industrial Capture Parameters**: Promiscuous mode toggle, Snaplen configuration (`65535 Bytes` full frame vs. `96 Bytes` line-rate header truncation to prevent OOM under high-throughput backbones), and 16MB ~ 128MB pinned kernel ring buffer options.
- **Sub-Millisecond BPF Compiler Check**: Powered by `pcap::Capture::dead`, validating syntax in $<0.1\text{ms}$ with real-time feedback and exact character offset error reporting.
- **Built-in Industrial & Security BPF Presets**: Instant one-click loading for Modbus/TCP, Hydrology SL651-2014, MQTT, DNS, HTTP, TCP SYN Scan, ICMP Echo, and Multicast/Broadcast traffic.

### 2. Four-Fold Physical Storage & Persistent Evidence Preservation (`forensics.rs` / `export_engine.rs`)
- **Kernel-Level Streaming Raw Frame Append**: Every captured L2 wire frame is immediately appended to `forensic_capture.pcap` with standard libpcap binary headers (24B Global + 16B Packet Header) and mandatory `flush()` synchronization, guaranteeing zero evidence loss even across unexpected crashes or power failures.
- **Monotonic Blockchain Evidence Chain**: Each frame pushes the global SHA-256 tamper-evident chain (`advance_global_chain`) and is logged into `received_data.jsonl` with 30-day automatic rotation.
- **Persistent Packet Sample Library (`save_packet_sample_cmd`)**: Structure and archive suspicious packets into local sample storage with tags and raw payloads for future regression.
- **Golden Network Baseline Models (`save_network_baseline_cmd`)**: Freezes normal network protocol distributions, RFC 2544 packet lengths, and entropy baselines into `network_baselines.json`.
- **Universal Format Export**: One-click export to `.pcap` (Wireshark 100% compliant), `.pcapng`, `.csv`, and comprehensive Markdown/HTML audit reports.

### 3. Multi-GB PCAP Streaming Sparse Indexer & Nanosecond Replay (`pcap_sparse_indexer.rs` / `pcap_replay.rs`)
- **Constant $\mathcal{O}(1)$ Memory Sparse Window Paging**: Single-pass scan creates 32-byte sparse index nodes at Stride=500. 10,000,000 packets take only ~640 KB memory, enabling sliding-window paging across multi-GB PCAPs with zero OOM crashes.
- **High-Precision Timed Replay**: Replays captures at 0.01x~1000x realistic speed, TopSpeed line-rate saturation, or single-step manual stepping into virtual loopback pipelines.

### 4. Universal Multi-Bus Diff & Multi-Dimensional Traffic Analysis (`PacketDiffModal.vue` / `analyzer.rs`)
- **Byte-by-Byte LCS Hex Diff**: Highlights Match, Mismatch, Insert, and Delete bytes with precise mutation rate percentages.
- **Center-Star N-Sequence Alignment (MSA)**: Aligns 2~8+ packets simultaneously to compute conserved core protocol structures and cross-entropy spectrums.
- **RFC 2544 Standard 7-Tier Distribution**: Real-time traffic profiling (64, 128, 256, 512, 1024, 1518, Jumbo), Top Talkers, and packet arrival jitter (MAD).
- **Automated Dual-Pcap Cross-Audit (`pick_and_compare_network_pcap_cmd`)**: Audits live traffic against historical baseline captures.
